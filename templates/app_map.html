Mapa de Aplicaciones

Evidencia de relaciones derivada del análisis estático del código — NUNCA implica comunicación en tiempo real, dependencia operacional confirmada, ni que una aplicación ejecute a otra. Una flecha significa únicamente que existe evidencia estática compatible con Productor → tabla → Consumidor, usando la MISMA clasificación de Flujo de Datos (ver analyzer/data_flow.py) — nunca una segunda clasificación. Tablas indeterminado quedan excluidas: sin columnas reconstruidas, no hay evidencia de qué se relaciona con qué. Cuando dos apps comparten el mismo lado (ambas leen, o ambas escriben) de una tabla, esa relación se muestra aparte, nunca como flecha dirigida.
